# Security Policy

MamaAir handles sensitive wellbeing and location-related experiences. Please
report suspected security or privacy issues privately and responsibly.

## Reporting a vulnerability

Email [service@mamaair.work](mailto:service@mamaair.work) with the subject
`Security report`. Do not open a public GitHub issue containing exploit details,
credentials, personal data, or information that could put users at risk.

Include the following when available:

- the affected app version, commit, or endpoint;
- the potential security or privacy impact;
- clear reproduction steps using synthetic data;
- relevant logs or screenshots with secrets and user information removed;
- any suggested mitigation.

The maintainers will review the report and coordinate follow-up privately.
Public disclosure should wait until a fix or mitigation is available and an
appropriate disclosure timeline has been agreed.

## Supported versions

Security fixes are evaluated for the active `develop` branch and the latest
published Android release. Older builds may not receive fixes; users should
update to the latest available build.
